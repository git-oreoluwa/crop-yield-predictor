🌾 **Crop Yield Predictor**

A machine learning web app that predicts agricultural crop yield (hg/ha) based on country, crop type, rainfall, temperature, and pesticide usage, trained on 24 years of FAO crop data (1990–2013).

🔗 Live App: [oreoluwa-crop-yield.streamlit.app](https://o-crop-yield-predictor.streamlit.app/) 

📌 **Project Objective**

Poor yield forecasting contributes to food insecurity and inefficient agricultural supply chains, particularly for smallholder farmers who lack access to the predictive tools larger agribusinesses use. This project builds a regression-based machine learning model to predict crop yield and identify the key variables that most strongly influence it, with the goal of supporting better planning decisions across the agricultural supply chain.

This project combines my background in Agricultural Economics (B.Sc. Agriculture, research experience at IITA) with data analytics and machine learning skills developed through professional work and independent study.
